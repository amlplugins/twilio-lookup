# @amlplugins/twilio-lookup

Native `twilio` SDK re-exported under the `@amlplugins` namespace.

> Twilio Lookup — phone number validation, carrier lookup, line-type intelligence, identity match.

## Install

```bash
npm install @amlplugins/twilio-lookup
```

## Use

```ts
import { /* named exports from twilio */ } from "@amlplugins/twilio-lookup";
// or
import sdk from "@amlplugins/twilio-lookup";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
